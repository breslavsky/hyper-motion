# Pure Kinetic on native HyperFrames

The template keeps `film.json` and its existing panels. `node lib/film.cjs fit`
now builds native HyperFrames compositions instead of a whole-film JavaScript
player. HyperFrames owns playback, seeking, media timing and export.

## Responsibilities

- `source/lib/compiler/`: pure recipe compilation, look data and field schemas.
  It resolves beats, scene colours, transitions and semantic sound events before
  the browser opens. It has no browser player.
- `source/lib/build.cjs`: generates native hosts, reusable definition files,
  private variables and the project manifest. Transition overlap and the final
  half-beat hold are included in each host's declared bounds.
- `source/lib/components/`: instance-local factories, helpers, measured fitting,
  fonts, images and rendering. Each mounted scene has one paused GSAP timeline
  registered with HyperFrames. The root timeline handles presentation and
  transitions; it never advances a child's clock.
- `source/music.py`: renders the existing music bed and component sound events
  into the native audio track. Sound preparation is build-time work. Playback
  belongs to HyperFrames.

The catalogue contains 95 types: 88 primarily DOM, three Canvas and four WebGL.
Canvas and WebGL remain appropriate renderers inside native components; their
state is evaluated from the component's local time. This migration does not
replace their visuals with approximations. Fonts, GSAP and Three.js are local,
with pinned versions and provenance beside their source.

The small UI-world prototype lives separately at
`runtimes/hyperframes/components/ui-world/`: one world, actor and camera exposed
as one native HyperFrames scene. It complements full-frame scene composition.

## Brand and sound inputs

Existing `style`, `palette`, `brand.colors`, per-scene colours and looks remain.
`brand.font` selects `Geist`, `Archivo`, `Geist Mono` or `Instrument Serif`, or a
local font copied into the project:

```json
{
  "brand": {
    "name": "Nook",
    "colors": ["#187EE8", "#FFCA54"],
    "font": {"family": "Nook Sans", "src": "assets/nook.woff2", "weight": 600}
  },
  "palette": "brand"
}
```

Font loading finishes before text measurement. Each instance receives private
style data; another scene's overrides do not mutate the look catalogue. Text is
fitted within the existing design norms and measured limits. Invalid content is
reported instead of accepting arbitrary text and shrinking it without a floor.

Each scene can carry `sound`:

```json
{"sound": {"gain": 0.5, "kit": "tech", "mapping": {"tick": false, "chime": "ping"}}}
```

`mute: true` silences its events; gain is linear, from zero to two. Mapping can
replace a semantic sound kind or mute it with `false`. Visual hit impulses stay
unchanged when sound is muted. Events retain their owning scene, including a
transition sound that starts before that scene. Changing sound settings makes
the existing soundtrack stale until it is rebuilt.

## Musical timing

The dial's authored gesture accepts a span in beats relative to the scene:

```json
{
  "type": "dial", "beats": 12, "label": "Intensity", "value": 100,
  "timing": {"slide": {"startBeat": 2, "endBeat": 10}}
}
```

At 120 BPM the movement starts one second into the scene and finishes at five
seconds. Its tick crossings and arrival chime come from the same motion timing.
The music is not time-stretched. The finish must fit the actual scene duration
after applying pace. An explicitly timed gesture may exceed the usual short
scene recommendation, up to the normal 32-beat input limit.

The UI-world prototype supports the same `timing.slide` shape plus a musical
grid offset. Its camera and actor follow the retimed action and its native audio
clips are regenerated from the resulting events.

## Editing and extension

The authoritative template input is `film.json`. Run fit, audio and publish
after editing it. Generated HTML is reviewable output, not a second source of
truth. Native variables expose content, style, brand and product-interface
values for independent component use. Structural timing changes require a
rebuild. In the sequential `film.json` path, preview edits that alter semantic
timing report `rebuildRequired`, because a previously mixed soundtrack cannot
update itself in the browser.

Our component metadata lives in `components/metadata.cjs`; its browser copy is
generated by `tools/sync-component-metadata.cjs`. `tools/technique.py` extends
metadata, the catalogue and ESM factories, then applies the existing acceptance
gate. `tools/kinetic/guide.py` generates the film-writing guide from these facts.
The one-time conversion tool requires an explicit frozen source and a fresh
destination, so rerunning it cannot overwrite maintained components.

Existing projects retain their own files. Their validation remains compatible;
this repository change does not rewrite users' saved films or deploy a worker.

## Directed Document Flow sequences

`source/sequence.mjs` is a separate entry point for the constrained six-document
Folio production, with `document-flow.v1` input and `folio-02` choreography. It
emits one native graphics world, one camera and native audio clips. Its 26
semantic events include `action.start` for Collect / Arrange / Create and
`category.ready` when each group is complete. The existing scene catalogue and
worker routing remain separate.

Each mounted world owns `root.documentFlow`, its audit, variables and native
timeline identity. Root variables are inherited from a DOM-owned provider;
explicit child values win. Two aliases of the same graphics source are tested
with different brands, content, start times and independent disposal. Combining
worlds also requires assembling their native audio schedules; this does not
claim an automatic multi-world or arbitrary action-graph builder.

Document Flow uses an enforced native readiness contract for audio freshness.
Brand and copy edits remain live after fit checks only if resolved events,
sound settings, BPM and duration match the compiled audio. A semantic change
rejects `window.__hf.buildReady` with `DOCUMENT_FLOW_AUDIO_STALE`; ordinary native
CLI export fails until a fresh build from the edited recipe supplies matching
audio. This sequence has no `rebuildRequired` warning or singleton fallback.
Portable source preserves explicit instance IDs and rebuilds without the repo.

## Verification

The migration keeps the original plan comparison, text/fit audit and technique
gate. Native acceptance uses the pinned HyperFrames bundler and seeker, blocks
external asset requests and checks every child clock. The full matrix covers
all three aspects, looks, transitions, image branches, timed actions and
repeated definitions. Separate tests cover Canvas/WebGL sibling independence,
brand fonts, native variables and sound settings.

Frame comparisons use a frozen copy of the template from before migration.
Forward image bounds are unchanged. Reverse seeks require identical DOM and
component state; PNG equality is recorded separately because Chromium's
transformed-layer raster cache also changes edge pixels in the old template.
The comparison additionally bounds native raster variation against that old
reference under the same seek history. It does not treat differing scene state
or timeline values as a raster exception.

Reproduction commands (from the repository root):

```sh
node templates/pure-kinetic/tools/kinetic/plans.test.js
node --test templates/pure-kinetic/tools/migration-*.test.mjs
node templates/pure-kinetic/tools/audit.mjs --looks editorial --aspects 9:16,16:9,1:1 --known --twice
node templates/pure-kinetic/tools/migration-accept.mjs --extended --reference /path/to/frozen/source --out /tmp/pk-native-acceptance
PURE_KINETIC_TESTS=1 PURE_KINETIC_QUICK=1 .venv/bin/pytest -q
.venv/bin/ruff check .
```

Browser acceptance runs separately from the full Python suite to avoid running
the same expensive catalogue audit twice. Receipts identify the source hashes
actually tested; a changed runtime requires a corresponding follow-up check.

The recorded migration result is [tools/migration-acceptance.json](tools/migration-acceptance.json):
402/402 cases pass, including all 95 types in all three formats, 43 looks and
18 transitions. It retains the frozen baseline revision, source hashes and
explicit focused-check supersession. The independent full-length fit audit
passes 285/285 cases, with another 27/27 long Russian text and brand-font cases.
Original plan parity is 1468/1468; component and prototype Node tests are 51/51.
The final focused Python suite passes 67 cases (three browser gates run
separately); the actual native CI smoke passes all 12 cases.
Strict native video exports were also produced at 1080x1920, 1080x1080 and
1920x1080, with audio. These measurements describe the tested inputs and do not
promise that unlimited arbitrary text or every possible font will fit.
